## Group moderation / omnibus hierarchy
For each outcome and comparator, Γ=Δr_SS−Δr_DS. Use paired stratified bootstrap percentile intervals and approximate centered-bootstrap two-sided tests; Holm across all 12 primary contrasts, separately six original-capture sensitivities. Test the joint six-comparator Γ vector for each primary outcome first: bootstrap covariance Σ, observed T=Γ'Σ^+Γ, centered bootstrap null T_b=(Γ_b−Γ)'Σ^+(Γ_b−Γ), add-one upper-tail p; Holm across the two primary omnibus tests. Sensitivity has its own single omnibus test. Save Σ, rank, T, df/rank, chi-square approximation and full bootstrap vectors. These are approximate bootstrap-Wald tests, not exact randomization tests; groups have different assigned physical dimensions. Report moderation before subgroup localization. Null omnibus does not prohibit requested subgroup transparency but means subgroup p differences cannot establish SS specificity, equivalence, or a causal dimension explanation.
