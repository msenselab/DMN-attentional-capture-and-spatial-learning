## Observed prediction and primary inference
Leave one participant out. Within each training fold center raw S using training-only SS/DS means; subtract that same group mean from held-out S. Screen raw Fisher-z edges with Pearson two-sided p<.01 (trainingN32, df30); positive-minus-negative signed strength; training-only intercept+strength OLS. Empty/constant-strength predicts centered zero. All seven observed models and unfavorable outcomes are reported. Do not tune threshold or choose features using held-out outcomes.

Exactly 10000 within-group outcome permutations, seed20261004; draw DS then SS each iteration using numpy default_rng. Repeat all fold centering, selection, fitting and prediction. Main p=min(1,2*min((upper+1)/10001,(lower+1)/10001)); correct all seven by Holm-7. Absolute-r permutation tail sensitivity, separately Holm-7. r is Pearson correlation of held-out predictions with fold-centered held-out target, with constant-prediction r stored as zero fallback, not a defined Pearson coefficient. Signed alignment matters: a negative r is not successful prediction. Descriptive rank orders signed r, not |r|. Also save RMSE and zero-prediction baseline RMSE, with no additional inferential family.

## Direct question: does Default predict best?
Report six paired observed deltas r_Default-r_other, using the same held-out participants. Do NOT use differences between significance statuses. Permuting S only tests a no-brain/behavior-association null and will NOT be called a test of equal network predictive performance.

For direct comparison, use an explicitly approximate participant bootstrap that refits the complete pipeline: 5000 stratified draws (DS17 then SS16 sampled with replacement, seed20261006). A participant's bootstrap multiplicity is its weight. For each held-out identity remove ALL its copies from training, compute weighted training-group means, weighted Pearson screen, weighted signed-strength OLS, and predict that identity; evaluate weighted held-out correlation over sampled identities. This prevents identical-participant leakage. Weighted Pearson screening uses replication-equivalent sample size (training sum of weights, df=n_train-2). Outcome centering remains training-only. Bootstrap identities absent from the draw have zero evaluation weight. Preserve shared participant draws across all seven models. Fail if a sampled group has fewer than two distinct identities; do not silently change cohort or reuse invalid training folds.

Save the full 5000x7 bootstrap correlation archive and identity weights. Report percentile 95% intervals for each paired delta; these are approximate full-pipeline bootstrap intervals, not independent-case Pearson intervals. Report centered-bootstrap two-sided p=(1+count(|delta_boot-delta_observed|>=|delta_observed|))/5001 and Holm across six comparisons, explicitly labeled approximate bootstrap inference. Require positive observed delta and Holm p<.05 for a directional advantage; Default can be described as reliably best across tested models only if it exceeds ALL six by these corrected paired tests AND has positively aligned corrected primary prediction. Otherwise distinguish observed ranking from evidence of superiority. Also report simultaneous Bonferroni percentile intervals for six deltas (quantiles .05/12 and 1-.05/12) as conservative approximate interval sensitivity, not an exact finite-sample guarantee. Small N, network-size differences, duplicate-bootstrap rank limitations and no external validation remain caveats.
